# 機能仕様書 (Functional Specification)

## 1. 概要 (Overview)

本仕様書は、Obsidianプラグイン `obsidian-presenter` が提供する機能仕様、記法ルール、Frontmatterスキーマ、操作体系、および出力仕様を定義します。

---

## 2. スライド分割・解釈仕様 (Slide Parsing Specification)

### 2.1 スライド分割ルール

プラグインは Markdown の見出し階層および区切り線をスキャンしてスライドを自動分割します。

| 要素             | 記法                                  | スライド種別        | 挙動                                                               |
| :--------------- | :------------------------------------ | :------------------ | :----------------------------------------------------------------- |
| **表紙スライド** | `# 見出し` (H1)                       | Cover (`cover`)     | プレゼン全体の表紙として認識。タイトル・サブタイトル等を中央配置。 |
| **通常スライド** | `## 見出し` (H2)                      | Content (`content`) | 各スライドの区切りとなり、上部にタイトル・アクセントバーを配置。   |
| **小見出し**     | `### 見出し` (H3), `#### 見出し` (H4) | -                   | スライド内のサブセクションとして表示（スライドは分割しない）。     |
| **明示的区切り** | `---` (3つ以上のハイフン)             | Content (`content`) | 見出しを伴わない任意の改スライドを行う。                           |

> [!NOTE]
> コードブロック（` ``` ` または ` ~~~ `）内の見出しや `---` は、スライド境界として誤認識されないよう無視されます。

## 3. 設定とフロントマター仕様 (Settings & Frontmatter Specification)

### 3.1 ゼロ設定（フロントマター不要）の原則
**スライド作成にあたり、フロントマターの記述は必須ではありません（0行で動作します）。**

配色、ヘッダー、フッター、ロゴ、アスペクト比、カラムスタイルなどの共通設定は、Obsidianのプラグイン設定画面（**Settings → Presenter**）で一度指定しておけば、すべてのノートに自動適用されます。
フロントマターは、**「そのノート固有で特定の項目だけを上書きしたい場合」にのみ、必要な項目を1〜2行記述**します。

#### 記述例 1: 完全ゼロ設定（推奨・最もシンプル）
```markdown
# プレゼンタイトル

## スライド1
- 箇条書き
```

#### 記述例 2: 特定の項目のみ上書きする場合
```yaml
---
header: "2026年度 経営計画発表会"
accentColor: "#e11d48"
---
```

### 3.2 パラメータ一覧（設定画面とフロントマターの対応）

| フロントマターキー | 設定画面の対応項目 | 型 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `baseColor` (または `background`) | Default base color (background) | string (HEX/RGB) | `#ffffff` | スライドの背景色（ベースカラー） |
| `mainColor` (または `color`) | Default main color (text) | string (HEX/RGB) | `#1e293b` | 本文テキスト・見出しの基本文字色 |
| `accentColor` | Default accent color | string (HEX/RGB) | `#2563eb` | 強調テキスト、境界線、マーカーの色 |
| `header` | Default header | string | 空文字 | スライド上部に表示するヘッダーテキスト |
| `footer` | Default footer | string | 空文字 | スライド下部に表示するフッターテキスト |
| `logo` | Default logo | string | 空文字 | Vault内画像パス (`attachments/logo.png`) または外部URL |
| `aspectRatio` | Aspect ratio | `"16:9"` \| `"4:3"` | `"16:9"` | スライドの画面アスペクト比 |
| `columnStyle` | Default column style | `"card"` \| `"plain"` | `"card"` | カラムレイアウトの基本スタイル |

### 3.3 設定の優先度 (Priority Rule)

1. **最高優先**: ノートの Frontmatter 個別設定値（指定がある項目のみ）
2. **基本値**: プラグイン設定（Settings タブ）の保存値
3. **システム規定値**: プラグイン組込の初期値 (`DEFAULT_SETTINGS`)

## 4. グリッドレイアウト（マルチカラム）仕様

スライド内で横並び（2カラム・3カラム）を実現するための軽量構文を提供します。

### 4.1 セパレータ記法 (`::: cols-N` + `+++`)

```markdown
::: cols-2
### 左カラムの見出し
- ポイントA
- ポイントB
+++
### 右カラムの見出し
- ポイントC
- ポイントD
:::
```

- `::: cols-2`: 2カラム均等グリッドを生成
- `::: cols-3`: 3カラム均等グリッドを生成
- `::: cols-2 plain`: 背景色・枠線なし（プレーン分割レイアウト）で2カラム生成
- `::: cols-2 card`: 背景色・枠線・余白あり（カード風レイアウト）で2カラム生成
- `+++`: 各カラムの境界線

### 4.2 コンテナ記法 (`::: columns` + `::: column`)

```markdown
::: columns plain
::: column
左カラムの内容
:::
::: column
右カラムの内容
:::
:::
```

- `::: columns`: 自動カラム数または指定カラム数のグリッドを生成
- `::: columns 2 plain`: 2カラム・プレーンスタイル（背景・枠線なし）を指定
- `::: columns 3 card`: 3カラム・カード風スタイル（背景・枠線あり）を指定

### 4.3 スタイルオプション（カード vs プレーン）

| スタイル | 特徴 | 適用方法 |
| :--- | :--- | :--- |
| **`card`** (デフォルト) | 背景色（`rgba(120, 120, 120, 0.04)`）、枠線、角丸、内側パディングを持つカード風 | `::: cols-2 card` または `columnStyle: card` |
| **`plain`** | 背景色なし（透明）、枠線なし、パディング `0`。カラム間の余白（gap）のみで並ぶプレーンなテキスト配置 | `::: cols-2 plain` または `columnStyle: plain` |

> [!NOTE]
> スタイルの優先順位は **ブロック構文（`plain` / `card`） > フロントマター（`columnStyle`） > プラグイン設定（`defaultColumnStyle`）** です。

### 4.4 HTML直接記述

```html
<!-- カードスタイル -->
<div class="presenter-cols presenter-cols-2 presenter-cols-card">
  <div class="presenter-col">左カラム</div>
  <div class="presenter-col">右カラム</div>
</div>

<!-- プレーンスタイル（背景色・ボーダーなし） -->
<div class="presenter-cols presenter-cols-2 presenter-cols-plain">
  <div class="presenter-col">左カラム</div>
  <div class="presenter-col">右カラム</div>
</div>
```

## 5. ラベル・バッジ装飾仕様 (Badge Specification)

### 5.1 構文仕様
`[xxx] テキスト` の形式で記述された文字列を検出し、`<span class="presenter-badge">xxx</span>` に変換します。

- **検出対象**:
  - `[重要]`, `[課題]`, `[STEP 1]`, `[FAQ]` などの角括弧で囲まれた任意のテキストラベル。
  - 行頭、見出し（H1〜H4）、リスト項目（`- [xxx] ...`）、テーブルセル、段落内などで使用可能。
- **除外・誤判定防止ルール**:
  - Markdown標準リンク `[テキスト](URL)` は変換しない（直後に `(` がある場合）。
  - 内部リンク（Wikilink） `[[ノート]]` は変換しない（前後に `[` や `]` がある場合）。
  - 画像リンク `![alt](URL)` は変換しない（直前に `!` がある場合）。
  - タスクチェックボックス `[ ]`, `[x]`, `[X]` は変換しない。
  - 脚注参照 `[^1]` は変換しない。
  - リンク定義 `[id]: URL` は変換しない。
  - コードブロック（フェンスコードおよびインラインコード `` `[xxx]` ``）内は変換しない。

## 6. 操作・ナビゲーション体系 (Controls Specification)

### 6.1 キーボードショートカット

| 操作                       | キーバインド                            |
| :------------------------- | :-------------------------------------- |
| **次のスライドへ**         | `→`, `↓`, `Space`, `PageDown`, `L`, `J` |
| **前のスライドへ**         | `←`, `↑`, `PageUp`, `H`, `K`            |
| **最初のスライドへ**       | `Home`                                  |
| **最後のスライドへ**       | `End`                                   |
| **全画面切り替え**         | `F`                                     |
| **印刷 / PDFエクスポート** | `P`                                     |
| **スライド終了 (閉じる)**  | `Escape`                                |

### 6.2 ナビゲーションツールバー (Floating Toolbar)

画面下部中央にフローティング配置され、マウスホバー時に鮮明に表示されます。

- **前へ / 次へ ボタン**: スライド移動
- **スライド番号ボタン (`X / Y`)**: クリックで「スライド番号ジャンプモーダル」を開く
- **全画面ボタン**: フルスクリーン表示の切り替え
- **印刷ボタン**: 印刷ダイアログを起動
- **閉じるボタン (`X`)**: プレゼンテーションを終了

## 7. 印刷・PDF出力仕様 (Print & PDF Specification)

- **メカニズム**:
  ブラウザ／Obsidian の標準印刷機能（`window.print()`）と `@media print` CSS によるページング制御。
- **改ページ保証**:
  すべてのスライドカード要素に `break-after: page;` および `page-break-after: always;` を適用。
- **UI要素の非表示**:
  印刷時には進行状況バー、ツールバー、エディタ背景はすべて自動的に非表示となり、スライド面のみが純白背景上でランドスケープ（横向き）出力されます。
