# UI/UX・スタイリング設計書 (UI/UX & Styling Design Document)

## 1. デザイン原則 (Design Principles)

1. **コンテンツ主導 (Content-First)**:
   スライド作成者がテキストと論理構成に集中できるよう、余計な装飾を排し、高い可読性と洗練された余白を提供します。
2. **動的デザイントークン (Dynamic Design Tokens)**:
   CSSカスタムプロパティ（CSS変数）を採用し、フロントマターで指定されたカラーが瞬時に全UI要素へ調和して波及する仕組みを構築します。
3. **レスポンシブ・アスペクト比維持 (Scale & Ratio Fidelity)**:
   ディスプレイサイズや解像度に関わらず、16:9 または 4:3 のスライド比率を崩さず、常に最適な拡大率（Scale Transform）でセンタリング表示します。

---

## 2. デザイントークン・CSS変数 (Design Tokens)

スライドカード（`.presenter-slide-card`）に対して、以下の変数が動的にバインドされます。

```css
.presenter-slide-card {
  --presenter-base-color: #ffffff;   /* ベースカラー: スライド背景色 */
  --presenter-main-color: #1e293b;   /* メインカラー: 本文・見出し・基本文字 */
  --presenter-accent-color: #2563eb; /* アクセントカラー: 強調・ライン・マーカー */
}
```

### 2.1 配色マッピング表

| 要素                                    | 適用プロパティ               | 参照変数                                              |
| :-------------------------------------- | :--------------------------- | :---------------------------------------------------- |
| **スライド背景**                        | `background-color`           | `--presenter-base-color`                              |
| **本文・段落**                          | `color`                      | `--presenter-main-color`                              |
| **H1 (表紙見出し)**                     | `color`                      | `--presenter-accent-color`                            |
| **H2 (スライド見出し)**                 | `color` / `border-bottom`    | `--presenter-main-color` / `--presenter-accent-color` |
| **箇条書きマーカー**                    | `li::marker`                 | `--presenter-accent-color`                            |
| **太字 (`strong`)**                     | `color`                      | `--presenter-accent-color`                            |
| **引用 (`blockquote`)**                 | `border-left-color`          | `--presenter-accent-color`                            |
| **ラベル・バッジ (`.presenter-badge`)** | `background-color` / `color` | `--presenter-accent-color` / `#ffffff`                |
| **進捗バー**                            | `background`                 | `--presenter-accent-color`                            |

## 3. レスポンシブスケーリング設計 (Responsive Scaling Strategy)

### 3.1 基準解像度 (Base Coordinate System)

- **16:9 基準サイズ**: `1280px × 720px`
- **4:3 基準サイズ**: `1280px × 960px`

### 3.2 拡大縮小計算ロジック

スライドステージ（`.presenter-stage`）の実際の描画領域サイズ（`stageWidth`, `stageHeight`）を取得し、`ResizeObserver` を通じて動的にスケール係数を算出します。

```typescript
const scaleX = (stageWidth - padding) / baseWidth;
const scaleY = (stageHeight - padding) / baseHeight;
const scale = Math.min(scaleX, scaleY, 1.5);

cardEl.style.width = `${baseWidth}px`;
cardEl.style.height = `${baseHeight}px`;
cardEl.style.transform = `scale(${Math.max(scale, 0.2)})`;
```

- **利点**:
  - CSSの `font-size` やマージンをビューポートごとに再計算する必要がなく、文字の折り返し位置やレイアウトバランスが100%固定されます。
  - プロジェクター投影、大画面モニター、ノートPC画面のいずれでも同一の美しいスライド姿を保持します。

## 4. タイポグラフィ・レイアウト階層 (Typography & Hierarchy)

### 4.1 表紙スライド (`.presenter-slide-cover`)

- **配置**: 上下左右中央揃え (`justify-content: center; align-items: center;`)
- **H1**: `font-size: 54px`, `font-weight: 800`, `line-height: 1.2`
- **サブタイトル/段落**: `font-size: 24px`, `opacity: 0.85`

### 4.2 通常スライド (`.presenter-slide-content`)

- **H2 (アクションタイトル)**: `font-size: 28px`, `font-weight: 700`, 下部にアクセントボーダー (3px)
- **H3 (小見出し)**: `font-size: 22px`, `font-weight: 600`
- **本文 (p, li)**: `font-size: 20px`, `line-height: 1.5`
- **カラム内密度適応 (`.presenter-col`)**:
  - **2カラム**: `h3: 19.5px`, `p/li: 17.5px`, `padding: 15px 18px`
  - **3・4カラム (`.presenter-cols-3`, `.presenter-cols-4`)**: `h3: 18px`, `p/li: 16px`, `padding: 13px 15px`
  - **2段スタック / Callout併用複合レイアウト**: 行間マージンとパディングを自動圧縮し、Bento・2軸マトリクス・エグゼクティブサマリー等が100%スケールで16:9枠内に収まるよう最適化
- **テーブル (table)**: `font-size: 17px`（カラム内は `15px`）、均等パディング、薄いグリッド線
- **コードブロック (pre)**: `font-size: 16px`, 角丸8px

### 4.3 スマートスライドレイアウト・タイポグラフィ

- **中扉スライド (`.presenter-slide-section`)**:
  - 見出しのみで構成されるスライドをアジェンダ・章区切りカードとして中央配置。
  - `font-size: 44px`, `font-weight: 800`, タイトル上下にアクセント装飾ラインを配置。
- **引用・ステートメントスライド (`.presenter-slide-quote`)**:
  - 単一ブロッククォート（`> ...`）をスライド中央に大判フォント（`font-size: 30px`）で表示。
  - 左ボーダーのアクセントカラー強調とイタリック調の洗練された文字組。
- **KPIビッグナンバーカード (`.presenter-kpi-metric`)**:
  - 単独行の太字数値（例: `**+140%**`, `**3.5x**`）を自動検知。
  - `font-size: 44px`, `font-weight: 800`, アクセントカラー（`--presenter-accent-color`）を適用した巨大インジケーターとして描画。
- **結論サマリーボックス (`.presenter-slide-card .callout`)**:
  - `> [!important]`, `> [!tip]`, `> [!warning]` などの結論Calloutを、枠線・背景ティント・アイコン付きのサマリーボックスとして配置。

## 5. フローティングツールバー UX (Toolbar UX)

- **UIスタイル**: グラスモルフィズム（半透明ダーク背景 `rgba(15, 23, 42, 0.82)` + `backdrop-filter: blur(14px)`）
- **インタラクション**:
  - 通常表示時はプレゼンテーションに没入できるよう、透明度 `0.3` で控えめに表示。
  - マウスをツールバー周辺にホバーすると `opacity: 1` にスムーズにトランジション。
  - 各ボタンには Obsidian 標準の Lucide アイコンを採用し、ホバーエフェクトと明確な aria-label を付与。
  - **前へ / 次へ ボタン**: ページ送り
  - **スライド番号ボタン (`X / Y`)**: クリックでスライド番号直接ジャンプモーダルを表示
  - **スライド俯瞰ボタン (Grid)**: クリック（または `G`/`O` キー）で全スライドのサムネイルタイル一覧（Overview Grid）を表示
  - **発表者ノートボタン**: 現在のスライドにノート（`> [!note]`）が存在する場合は右上にアクセントドット（インジケーター）が点灯。開閉状態に応じてアクティブハイライト
  - **はみ出し警告ボタン (`⚠ N`)**: カード境界を縦にはみ出しているスライドが存在する場合にのみ自動出現。クリックではみ出し検査モーダルを開く
  - **全画面ボタン**: フルスクリーン表示の切り替え
  - **印刷・エクスポートボタン**: クリックで「Print slides only」「Print handout with notes」「Export as powerpoint (.pptx)」のドロップダウンメニューを展開
  - **閉じるボタン (`X`)**: プレゼンテーションを終了

## 6. リアルタイムプレビューペイン UI/UX (Preview Pane UX)

### 6.1 ペイン構成とテーマ調和
- **コンテナ (`.presenter-preview-container`)**:
  Obsidian のテーマ変数（`--background-secondary`）と調和したダーク/ライト適応背景。
- **上部ツールバー (`.presenter-preview-toolbar`)**:
  半透明背景（`rgba(15, 23, 42, 0.7)`）とバックドロップブラー（`blur(8px)`）を採用した洗練されたバー。
  - ページ送り（前へ・次へ）と現在位置カウンター表示（`X / Y`）。
  - **カーソル追従トグル（ピンボタン）**:
    追従有効時はアクセントカラー（`--interactive-accent` / `#38bdf8`）のハイライト背景と境界線でアクティブ状態を明示。
  - **スライド・テンプレート・ナビゲーターボタン (`layout-template`)**:
    プレビューを確認しながら1クリックでテンプレートナビゲーターを開き、目的別のスライド構成スニペットを即座に挿入。
  - **全画面プレゼンボタン**:
    プレビュー状態から1クリックでフルスクリーンプレゼンテーションを開始。
- **プレビューキャンバス (`.presenter-preview-stage`)**:
  - `ResizeObserver` による追従拡大縮小。狭小なサイドバー幅（300px前後）から大型の分割ペインまで、スライドのアスペクト比を1ピクセルも崩さず美しくセンタリング描画。
  - スライドカードに繊細なドロップシャドウ（`box-shadow: 0 12px 32px rgba(0, 0, 0, 0.35)`）を施し、エディタとの視覚的分離と立体感を演出。
- **空状態（Empty State）**:
  Markdownファイルが開かれていない場合は、落ち着いたミュートカラーでガイダンスメッセージを表示。

## 7. 発表者ノートドロワー UI/UX (Speaker Notes Drawer UX)

### 7.1 ドロワーの構造とアニメーション
- **配置**: スライドステージ下部に固定され、下から上へスムーズにスライドイン展開（`animation: presenterDrawerSlideUp 0.2s ease-out`）。
- **ビジュアル**:
  - ダークトーン（`rgba(15, 23, 42, 0.95)`）＋ バックドロップブラー（`blur(12px)`）による高級感のあるガラス調インターフェース。
  - 最適な高さ制限（`height: 220px; max-height: 38vh`）により、スライド投影領域を過度に圧迫しない設計。
- **ヘッダー**:
  - アイコン付きタイトル（`Speaker notes & details`）および最小化ボタン（`chevron-down`）。
- **コンテンツ領域**:
  - 縦スクロール対応（`overflow-y: auto`）、可読性の高い文字サイズ（14px）と行間（1.6）。
  - ノートが存在しないスライドではイタリック体で「No speaker notes for this slide.」と静かに案内。

### 7.2 スライドステージとの排他・自動リサイズ調和
- ノートドロワーの開閉（`N` キーまたはトグルボタン）が行われると、ステージの利用可能高さの変化を検知して `applySlideScale()` が即時実行されます。
- スライドカードのスケール（縮小率）が自動的に再調整されるため、**ノートドロワーがスライド本文や図表と重なる事故を100%防止**します。

## 8. 配布用Web資料・ハンドアウト UI/UX (Handout & Standalone Web UX)

### 8.1 単一HTMLエクスポートの受取手体験
非エンジニアがブラウザでダブルクリックした際、一切の初期設定やプラグインなしで直感的に読めるよう、以下のUI/UXを提供します。

- **ヘッダーバー (Top Navbar)**:
  - 左端: ドキュメントタイトルと「Presentation」バッジ。
  - 中央/右端: **[ 🖥 スライド表示 ]** と **[ 📄 配布資料（詳細解説）表示 ]** のデュアルビュースイッチ。
  - 補助ツール: ノート開閉ボタン（`📝 ノート`）、印刷ボタン（`🖨 印刷 / PDF`）。
- **🖥 スライド表示モード**:
  - 矢印キーやスペースキーで軽快にめくれるフルスクリーン・スライドショー。
  - 画面下部にフローティングナビゲーションコントローラーを完備。
- **📄 配布資料（ハンドアウト）表示モード**:
  - 縦スクロールで上から下へすらすら読める、Notion公開記事や洗練されたWebレポート風のデザイン。
  - 各スライドカードの下に、アクセントバッジ（`💡 解説・背景メモ`）とともに `> [!note]` の詳細解説が展開。
  - 箇条書きスライドだけでは伝わらない「なぜ」「背景」「口頭で話したニュアンス」が文章として補完され、会議の欠席者や役員でも100%理解できるドキュメント体験を実現。

### 8.2 ハンドアウト印刷（A4最適化）レイアウト
- 印刷（またはPDF保存）実行時、1ページにつき「上部: スライドカード（高さ380px） ＋ 下部: 詳細解説ノート（破線区切り）」という美しい SlideDoc 形式で出力。
- ページ送りが自動制御され、紙で配布してもWebでPDF保存しても破綻しないプロ品質の資料が完成します。

## 9. スライド俯瞰一覧 UI/UX (Overview Grid / Slide Sorter UX)

- **目的**: 質疑応答（Q&A）や全体構成の確認時に、全スライドを俯瞰して任意のスライドへ瞬時に移動する。
- **起動と閉じる**:
  - キーボード: `G` または `O` キー
  - ツールバー: グリッドアイコン
  - 閉じる: `Escape`、背景クリック、またはスライドタイルクリック
- **ビジュアルデザイン**:
  - 全画面ダークオーバーレイ（`rgba(15, 23, 42, 0.88)` + `backdrop-filter: blur(8px)`）。
  - レスポンシブなグリッドレイアウト（`grid-template-columns: repeat(auto-fill, minmax(220px, 1fr))`）。
  - 各サムネイルカードにはスライド番号バッジ、タイトル、およびレイアウト種別を表示。
  - 現在アクティブなスライドカードにはアクセントカラーの強調枠線を付与。
  - 中扉スライド（`section`）はアクセント背景・センタリングタイトルで章の区切りを直感的に視認可能。
  - はみ出し（Overflow）が発生しているスライドにはサムネイル上に `⚠` 警告バッジを表示。
- **スタンドアロンHTMLとの完全互換**:
  - Obsidian内だけでなく、エクスポートされた単一HTMLファイル上でも上部ナビゲーションの「📑 一覧 / 目次」ボタンや `G` / `O` キーから全く同一の俯瞰一覧・目次体験を提供。配布資料（ハンドアウト）モード時も該当スライドの解説ブロックへスムーズスクロールで移動可能。

## 10. 画像・ダイアグラム拡大表示 UI/UX (Lightbox UX)

- **対象要素**: スライド内の画像（`<img>`）および Mermaid ダイアグラム（`.mermaid svg`）。
- **トリガー**: クリック操作（マウスカーソルが `zoom-in` に変化）。
- **ビジュアルと挙動**:
  - 全画面オーバーレイ（`rgba(0, 0, 0, 0.85)` + フェードインアニメーション）。
  - 元画像・SVGのアスペクト比を100%維持しながら、画面いっぱいにセンタリング拡大表示（最大幅 90vw、最大高さ 90vh）。
  - 右上にクローズボタン (`✕`) を配置。
  - `Escape` キー押下、背景クリック、または拡大図クリックでスムーズに元のスライドへ復帰。
- **スタンドアロンHTMLとの完全互換**:
  - Obsidian内だけでなく、エクスポートされた単一HTMLファイル上でも全く同一のLightbox体験を提供。

## 11. スライドはみ出し検査モーダル UI/UX (Overflow Inspection Modal)

- **目的**: スライド作成中にテキストやカラムがカード境界枠を突き抜けてしまう問題を早期に発見・解消する。
- **インジケーター**:
  - ツールバーにはみ出しスライド件数（例: `⚠ 2`）が警告カラー（アンバー/オレンジ）のバッジとして点灯。
- **モーダルUI (`OverflowReportModal`)**:
  - はみ出しが発生しているスライドの一覧、超過率（例: `+22% overflow`）、および原因要素を一覧表示。
  - 各項目に「ジャンプして確認」ボタンおよび「**Split slide**（ワンクリック分割）」ボタンを配置。
  - 「Split slide」を押すと、2つ目のH3見出しの直前に `---` が自動挿入され、エディタ履歴経由で2枚のスライドに綺麗に分割（`Cmd + Z` で即時取り消し可能）。

## 12. スライド・テンプレート・ナビゲーター UI/UX (`TemplateNavigatorModal`)

- **目的**: 執筆者が「このスライドで何を伝えたいか（目的）」から最適なレイアウトの型を選び、トップファームの設計原則・厳格ルールを参照しながら、実践的な Markdown スニペットを1クリックでエディタへ挿入できるようにする。
- **ビジュアルトーン**:
  - コンサルティングファーム基準の深いネイビー（`#0B2265`）、視線を誘導するアクセントオレンジ（`#FF6B00`）、ノイズのないライトグレー背景（`#F5F5F5`）を基調とした洗練された2ペイン＆カードUI。
- **3つのナビゲーションタブ**:
  1. **目的から探す (`usecase`)**:
     - 左サイドバーに12種類の伝達目的（「Q. スライドで何を伝えたいですか？」）を配置。
     - 右メインペインに選択した目的に対する「推奨テンプレート」および「代替パターン」カードをCSSワイヤーフレーム図解（`renderTemplatePreviewIcon`）付きで提示。
  2. **全テンプレート (`all`)**:
     - 「動的構造（ステップ・フロー）」「静的構造（比較・対比・構造）」「定量分析構造（データと証拠）」「サマリー構造（統合と俯瞰）」の4カテゴリ・全13種類のテンプレートを一覧表示。
  3. **デザイン絶対原則 (`principles`)**:
     - 黄金の配色比率（70:25:5の法則）、タイポグラフィの厳格化、ホワイトスペースとグリッド、SCQAとピラミッド原則、アクションタイトルの義務化、1スライド・1メッセージの徹底の6原則をカード形式で解説。
- **テンプレート詳細・挿入ビュー**:
  - カードをクリックすると詳細画面へ遷移し、「💡 構造と意図 / 最適なシーン」「⚖️ トップファームの厳格なルール」「📝 挿入されるMarkdownスニペット」を表示。
  - **「＋ 新規スライドとして挿入（推奨）」**（アクションタイトル見出し＋ボディ構成）と **「＋ 現在のスライドにレイアウトのみ挿入」**（ボディ構成のみ）、および **「📋 Markdownスニペットをコピー」** の3つのアクションを提供。

### 12.1 デザインテンプレート・クイックピッカー UI/UX (`TemplatePickerModal` & Command Palette)

- **Who（対象ユーザー）**:
  - キーボードから手を離さず（マウスに持ち替えず）、`Cmd + P`（コマンドパレット）やホットキーのみで高速にスライド構成を組み立てたいパワーユーザー。
  - すでに挿入したいテンプレート（ピラミッド、2軸マトリクス、ファネル、エグゼクティブサマリー等）が決まっており、タブ遷移なしで即座に挿入したい執筆者。
- **What（提供するUX）**:
  1. **インクリメンタル検索ピッカー (`TemplatePickerModal` / `SuggestModal`)**:
     - コマンド `Presenter: Insert slide design template...` (`insert-design-template`) で起動。
     - 各サジェスト行の左側に **ミニチュアCSSワイヤーフレーム図解 (`renderTemplatePreviewIcon`)** を表示し、テンプレート名、カテゴリバッジ、ディレクティブ構文（`<!-- columns pyramid -->` 等）、および最適な利用シーンをコンパクトに一覧表示。
     - 日本語・英語キーワード（例: `matrix`, `マトリクス`, `pyramid`, `ピラミッド`, `funnel`, `ファネル`, `chart`, `bento`, `executive`, `kpi` など）で瞬時に絞り込み可能。
  2. **文脈に応じたスマート挿入 (`resolveSmartInsertMode`) と修飾キー**:
     - `Enter`: カーソル位置の文脈を解析し、現在のスライドに既に `## 見出し` が書かれていて本文がまだ空（または見出し行にカーソルがある）場合は見出し重複を防ぐため **`body-only`（レイアウト枠のみ）** を自動選択し、それ以外では **`full-slide`（`## アクションタイトル` ＋ レイアウト本文）** を自動挿入。
     - `Shift + Enter`: 明示的に **`body-only`（レイアウト枠のみ）** を挿入。
     - `Cmd / Ctrl + Enter`: 明示的に **`full-slide`（新規スライド全体）** を挿入。
  3. **全13種のダイレクト挿入コマンド (`insert-template-*`)**:
     - コマンドパレットから直接特定のデザインテンプレートを1ステップで挿入でき、**Settings → Hotkeys** からよく使うテンプレートに専用ショートカットキーを割り当て可能。

## 13. 配布資料（ハンドアウト）目次サイドバー UI/UX (Handout TOC Sidebar UX)

- **目的**: 縦スクロール形式の配布資料モードにおいて、資料全体の構成を俯瞰し、目的のセクションやスライドへ迅速に移動できるようにする。
- **配置とレイアウト**:
  - メインコンテンツの左側に配置された固定追従（Sticky）サイドバー（幅 260px、画面高さいっぱいで独立スクロール可能）。
  - 白背景カードスタイル、角丸12px、上質なドロップシャドウでメインコンテンツと自然に調和。
- **階層型目次（Hierarchical TOC）**:
  - 中扉スライド（`section`）を親の章見出しとして太字アイコン付き（`📌`）で配置。
  - セクション配下のスライドをインデントされたサブリストとして番号付きで展開。
  - セクションスライドが存在しない場合は、全スライドが番号順に並ぶフラットリストへ自動フォールバック。
- **インタラクション**:
  - 各項目クリックで該当スライド（`#handout-item-${idx}`）へスムーズスクロール（上部ナビバーの高さ72pxを考慮したマージンオフセット）。
  - IntersectionObserver によるスクロールスパイ連動で、現在閲覧中のセクション/スライドが目次内でリアルタイムにハイライト（`is-active`）。
- **レスポンシブ & 印刷対応**:
  - 画面幅 1024px 以下の環境では、サイドバーが上部にレイアウトされ横スクロール/縦並びに自動適応。
  - 印刷時（`@media print`）は自動的に非表示となり、配布用印刷物のレイアウトを崩さない。
